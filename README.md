<h3>installation</h3>

1. install <a href="https://vencord.dev">vencord</a>.
2. open discord settings → vencord → themes.
3. download your preferred css file.
4. move it into your themes folder.
5. enable the theme.

<h3>customization</h3>

edit the css variables inside either theme to customize fonts, colors, backgrounds, spacing, and borders.
